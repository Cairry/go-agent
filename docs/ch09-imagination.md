## 个人应用场景

### 场景一：语音播客自动化

```
你的工作流 ──► 数字员工 ──► 播客节目

[你] 每天推送 3 条感兴趣的话题给 Agent

[Agent 自动执行]
• web_fetch 搜集多来源信息
• 整合、筛选、去重
• 撰写 8 分钟播客稿（自然语言风格）
• 调用 TTS API 生成语音文件
• 上传到播客平台（通过 API 或自动化脚本）

[你收到通知] 今日播客已发布，点击收听
```

技能：`daily-podcast`
工具：web_fetch、bash（TTS + 上传）、write

### 场景二：自媒体内容自动化

```
[你] 发现一个有趣的英文视频链接

[Agent 自动执行]
• 下载视频（web_download 或 yt-dlp）
• 提取字幕或语音转文字（Whisper API）
• 翻译成中文，调整表达
• 压缩视频 + 添加中文字幕（ffmpeg）
• 生成配套文案（微博/小红书风格）
• 通知你审核，确认后发布

[你] 审核 30 秒，点击确认发布
```

技能：`video-localize`
工具：bash（ffmpeg、yt-dlp）、web_fetch、write

### 场景三：个人知识库

```
[你] 每次看到好文章，发给数字员工

[Agent 自动执行]
• web_fetch 抓取全文
• 提取核心观点、关键数据
• 按主题分类（技术/商业/科学/人文）
• 写入 knowledge/主题/YYYY-MM.md
• record_note 关键术语和知识点

[你问] 上次你说的关于 Attention 机制的那篇文章讲了什么？

[Agent 使用 recall_note + grep 快速找到并回答]
```

技能：`knowledge-capture`
工具：web_fetch、write、record_note、recall_note

### 场景四：个人财务监控

```
[每月1日，Cron 触发]

• bash 抓取银行账单 CSV（或手动上传）
• 解析支出分类（餐饮/交通/购物/订阅）
• 与上月对比，找出异常支出
• 生成月度财务报告（图表用 ASCII art）
• 推送到手机

[你] 收到通知，月报显示本月订阅服务多了 3 个，节省空间
```

## 企业应用场景

### 场景一：培训材料自动生成

```
[输入] 产品说明文档、FAQ、操作手册

[Agent 自动执行]
• 分析文档结构和受众
• 拆解成知识点
• 为每个知识点生成：
  - 讲解文字（通俗易懂）
  - 练习题和答案
  - 常见误区提示
• 生成 PPT 大纲（Markdown → 可导入）
• 生成讲师手册

[输出] 完整培训套件，节省 80% 内容制作时间
```

### 场景二：合同/方案智能审查

```
[法务团队日常]

[你] 把合同上传给 Agent，
      "检查是否有对我方不利的条款"

[Agent 执行]
• 读取合同全文
• 对照审查清单（在技能文件中定义）：
  - 违约金条款是否对称？
  - 知识产权归属是否明确？
  - 争议解决条款是否合理？
  - 保密范围是否过宽？
• 生成风险报告，高/中/低优先级标注
• 建议修改措辞

[输出] 5 分钟完成初步审查，法务只需确认高风险项
```

### 场景三：数据报表助手

```
[每周一早 9 点，自动触发]

• 从数据仓库导出上周数据（bash 调用 SQL 脚本）
• 计算关键指标（Python 脚本）
• 与目标对比，标注超标/未达目标
• 识别异常波动（涨跌超过 20%）
• 生成管理层周报（中文，通俗表达）
• 发送到企业 IM（钉钉/企微）

[管理层] 打开 IM 直接看到周报，数据团队不再花半天手动整理
```

## 更多灵感清单

这些只是起点，随便列几个：

**科研助手**
- 监控 ArXiv，每天推送你感兴趣领域的新论文摘要
- 辅助文献综述：搜集、整理、找共同点和分歧
- 实验数据分析：从 CSV 到可视化到报告

**代码仓库管家**

- 自动 Code Review（PR 创建时触发）
- 依赖项安全扫描（每周检查 CVE 库）
- 自动生成 Changelog（从 commit message）
- 文档与代码同步检查

**游戏 NPC**
- 有记忆的 NPC：记住玩家的选择和对话历史
- 动态生成任务和对话，而不是固定脚本
- 随着游戏进展"成长"的角色

**个人学习助手**
- 每天推送专业领域新动态（30 分钟阅读量）
- 读完一篇文章后，用苏格拉底式提问检验理解
- 制定个性化学习计划，跟踪进度

**家庭自动化**
- 与智能家居 API 对接
- "出门前 30 分钟"自动检查清单
- 自动记录家庭支出和预算

## 构建你自己的数字员工

### 最小可行配置（5 分钟上手）

```bash
git clone https://github.com/your-repo/go-agent
cd go-agent
go build -o go-agent ./cmd

# 编辑配置
cp .agent/config/config.example.yaml .agent/config/config.yaml
# 填入 API Key

./go-agent
```

### 个性化第一步

1. **写 system_prompt.md**：告诉 Agent 你是谁，你的偏好和工作习惯
2. **第一个 record_note**：把最常用的信息告诉 Agent 让它记住
3. **第一个技能**：把你最频繁的重复性工作写成 SKILL.md

### 进阶配置

1. **开启 IM 模式**：配置 Server 酱，随时随地用手机下指令
2. **设置定时任务**：让 Agent 在你睡觉时继续工作
3. **添加自定义工具**：有特殊需求就在 `.agent/tools/bin/` 加工具

## 人机协作的哲学

贯穿这套教程的一个隐含主题：**这个项目本身就是人机协作的产物**。

没有人工智能，这个框架可能需要一个小团队花几个月开发。有了 Claude Code，一个人在几天内完成了同样的工作——不是因为 AI 替代了人，而是 AI 放大了人的能力。

这就是我们正在进入的时代：不是"AI vs 人类"，而是"人类 × AI"。

数字员工不是要取代你，而是帮你：
- 处理重复性工作，让你专注创造性工作
- 在你睡觉时继续工作
- 记住你会忘记的细节
- 以你一个人的时间，完成一个小团队的工作量

**你的创造力 + AI 的执行力 = 超级个体**
